# ☕ cafe-landing

가상의 카페 "모닝브루"를 소개하는 간단한 랜딩 페이지입니다. HTML과 CSS만으로 만들었고, AI 에이전트 수업 실습용으로 작성했습니다.

## 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | 페이지 본문 (히어로, 대표 메뉴, 카페 소개, 오시는 길, 푸터) |
| `style.css` | 스타일 및 모바일 반응형 레이아웃 |

## 실행 방법

별도 설치 없이 `index.html`을 브라우저로 열면 됩니다.

```bash
open index.html
```

## 참고

- 카페 이름, 메뉴, 가격, 주소는 모두 예시용 가짜 데이터입니다.
- 실제 카페 정보로 바꾸려면 `index.html`의 해당 텍스트를 수정하세요.
